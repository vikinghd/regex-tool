# Pcap Analyzer - 网络包分析工具

**版本**: 1.0
**日期**: 2026-06-04
**状态**: 已批准

---

## 1. 概述与目标

为网络工程师打造的专业 pcap 文件分析工具。支持本地 pcap 文件解析，提供会话追踪、流量统计、协议分类、IP-域名映射等核心功能。面向全球用户，极客风格界面。

## 4. 核心功能

### 4.1 文件上传

- 支持 .pcap / .pcapng 文件
- 前端解析（JavaScript pcap parser）
- 最大支持几百 MB

### 4.2 会话追踪

- 按 IP 对聚合数据包
- 显示每个会话的发送/接收量
- 可按任意列排序（升序/降序）

### 4.3 流量统计

- 整体汇总：总包数、总会话数、总流量、平均延迟、协议数
- Top IP 流量排名
- 协议分布百分比

### 4.4 IP-域名映射

- DNS 响应中提取 IP → 域名映射
- 缓存映射关系

### 4.5 会话详情

- 包列表（序号、时间、方向、协议、内容）
- 汇总分析（持续时间、延迟、重传率）
- 协议分布

## 5. 技术方案

### 5.1 技术栈

- **前端**: 纯 HTML + JavaScript（无框架）
- **pcap 解析**: pcap-parser 库或 WebAssembly
- **样式**: CSS（内联或单独文件）
- **路由**: 简单的 hash 路由（#/, #/session/:id）

### 5.2 发布形式

- **HTML 单文件**: 可直接用浏览器打开
- **后续可打包为 Electron exe**

### 5.3 数据流

1. 用户上传 pcap 文件
2. JavaScript 解析 pcap 原始数据
3. 按 IP 对聚合为会话
4. 计算统计信息
5. 渲染界面
